# lifestyle-app

A habit tracker (`/`, deployed to GitHub Pages — see `src/`).

## gym-tracker/

A standalone gym training tracker (plan sessions, log lifts, get progression
suggestions from a free rule-based coach). Not wired into the habit tracker's
navigation yet — see [`gym-tracker/README.md`](gym-tracker/README.md) for how
to run it and how it could be merged in later.

## life-os/

LIFE OS, a personal operating system (capture, planning, goals, reflection,
memory, and an AI advisor grounded in your own records). It is a separate
Next.js + PostgreSQL app with its own server, so it is not deployed to GitHub
Pages. See [`life-os/README.md`](life-os/README.md).
